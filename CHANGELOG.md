# Changelog

All notable changes to this project are documented here.
Format based on [Keep a Changelog](https://keepachangelog.com/) and [Semantic Versioning](https://semver.org/).

## [2.0.0] - 2026-11-05
### Added
- Professional repo structure (`assets/css`, `assets/js`, `assets/img`)
- About, Reviews, Featured and Contact sections plus footer
- Responsive layout with CSS-only hamburger menu
- Scroll-spy navigation and scroll-reveal animations
- `prefers-reduced-motion` support
- WebP hero image with PNG fallback via `<picture>`
- GitHub Actions workflow for GitHub Pages
- Issue and PR templates, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY
- Fully decorated README with animated banner

### Changed
- Hero image reduced from 7.9 MB to 1.3 MB PNG (160 KB WebP)
- Colors moved to CSS variables
- Developer credit added to page header and footer

## [1.0.0] - 2024-01-26
### Added
- Original animated car landing page (hero, rhombus layout, keyframe animations) by Nishat Mahmud
