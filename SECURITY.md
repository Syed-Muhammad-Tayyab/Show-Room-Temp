# Security Policy

This is a static front-end project with no server, database or user data handling.

## Reporting a vulnerability
If you find a security issue (for example an unsafe third-party script or link), please **do not open a public issue**. Use GitHub's **Security → Report a vulnerability** option on this repository, or contact the maintainer through https://github.com/Syed-Muhammad-Tayyab.

You can expect an initial response within a few days.

## Supported versions
Only the latest version on `main` is supported.
