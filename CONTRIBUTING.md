# Contributing

Thanks for helping improve **Cars.** 🚗 Developed by Syed Muhammad Tayyab.

## Getting started
1. Fork and clone the repo.
2. Create a branch: `git checkout -b feature/your-feature`.
3. Open `index.html` in a browser (or run `python -m http.server`).

## Guidelines
- Keep it dependency-free: plain HTML, CSS and vanilla JS.
- Follow `.editorconfig` (4 spaces, LF line endings).
- Use CSS variables from `:root` instead of hard-coded colors.
- Optimize images (prefer WebP with a PNG fallback).
- Test at desktop, tablet (~800px) and phone (~390px) widths.
- Respect `prefers-reduced-motion` for any new animation.

## Commit style
Use [Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `chore:`.

## Pull requests
Fill in the PR template, link the related issue and include screenshots for visual changes.
